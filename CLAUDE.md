# MEDSOILS frontend

Before re-reading the code, check the knowledge graph in `graphify-out/`:

- `graphify-out/GRAPH_REPORT.md`: communities, core nodes and connections.
- `graphify-out/graph.json`: raw graph (query it with `/graphify query "<question>"`).

The graph covers `src/`. It can lag behind recent edits, so confirm anything important in the file itself. Refresh it with `/graphify src --update`.
